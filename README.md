# Landing Page — Red Dead Redemption × Prime Video

Landing page conceitual de uma série de *Red Dead Redemption* no Prime Video. Projeto de estudo de front-end feito com HTML e CSS.

## Destaques

- Botões das temporadas abrindo os trailers
- Botão "Assistir" e cards de cenas com animação ao passar o mouse
- Responsivo: desktop, tablet e celular
- Imagens otimizadas em WebP (~13 MB → ~280 KB)
- HTML semântico e acessível (`nav`, `main`, `footer`, `aria-label`, foco visível)

## Rodando

Abra `Projeto-RDR-PrimeVideo/index.html` no navegador.

> Projeto de fã para estudo, sem vínculo com a Rockstar Games ou com o Prime Video.
